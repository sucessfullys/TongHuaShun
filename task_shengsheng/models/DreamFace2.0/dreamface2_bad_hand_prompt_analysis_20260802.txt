一、总体结论
- 本批样本 1668 张，bad=381，坏手/坏肢体率约 22.8%。
- 834 个模板中，有 85 个模板两次 seed 都 bad，占 10.2%；高于按 seed 独立估计的 5.2%，说明坏手不是纯随机噪声，部分 prompt 场景本身稳定高风险。
- 当某个模板一次 seed 出现 bad，另一次仍 bad 的概率约 44.6%，说明高风险 prompt 具有可复现性。
- 关键词模型 5 折 AUC 约 0.594：prompt 有风险信号，但不能只靠关键词完全预测，仍需结合构图、参考图、人物姿态和遮挡关系。

二、最容易出现坏手/坏肢体的场景
1. 腿部折叠、交叉、抱膝、盘腿、跷腿
   - 单变量 bad 率约 39.5%，是最强风险特征之一。
   - 常见问题不只在手，也会诱发腿/手混淆：抱膝、盘腿、翘腿时，手、膝盖、小腿、脚踝在画面中重叠，模型容易生成额外手掌、额外手臂、错位手腕，或把腿部纹理误接成手。
   - 适合设计：坐姿、地面坐、沙发蜷缩、床边抱膝、窗台盘腿、全身入镜。

2. 手靠近脸、头、头发
   - 单变量 bad 率约 32.1%，多变量后仍稳健。
   - 包括双手托脸、托腮、扶额、撩发、整理头发、手在脑后、手遮脸。
   - 高发原因：脸部是强身份保持区域，手指和头发边缘都很细，手掌贴近脸时容易出现多指、融合、额外手掌、手腕断裂。
   - 适合设计：近景/中近景，双手托腮，手指贴脸，头发遮住部分手腕，柔焦人像。

3. 持物、抱物、扶物、与道具接触
   - 单变量 bad 率约 26.3%，多变量后仍稳健；badcase 中 n_bad=140，是数量最多的一类风险来源。
   - 包括拿花、杯子、书、琴、帽子、包、伞、栏杆、门、椅子、沙发、乐器、手机、相机等。
   - 高发原因：手和物体发生接触/遮挡，模型要同时生成手指抓握、物体边缘、手腕方向，容易产生多余手指、额外手掌、手穿模、手臂与物体融合。
   - 适合设计：双手抱花束、手握栏杆、单手扶门另一手拿包、双手持乐器、手拿杯子靠近脸。

4. 全身或脚部细节入镜
   - 单变量 bad 率约 28.1%，多变量后仍稳健。
   - 全身构图会同时要求脸、衣服、手、腿、脚都清楚，身体远离镜头后手部像素变小，容易出现数量判断错误。
   - 常见问题：手在身体侧边变形、手和衣物边缘融合、手脚数量混乱、腿部结构牵连手部异常。
   - 适合设计：中全景/全身，脚踝/靴子/小腿入镜，人物占画面三分之二，复杂服装。

5. 多画面/拼贴/多姿态同图
   - 单变量 bad 率约 36.7%，两 seed 都 bad 占比约 20%。
   - 虽然样本数较少，但风险很高。模型需要在一张图中处理多个姿态或多张小图，每个小图手部区域更小，更容易多手、漏手、拼接错位。
   - 适合设计：三连拍、四宫格、杂志拼贴、多姿态同屏。

6. 躺姿、侧躺、俯卧、仰躺
   - 单变量 bad 率约 36.4%。
   - 躺姿会打破常规人体朝向，手臂被身体/床/衣物遮挡，容易在肩膀、腰侧、枕头附近生成多余手臂。
   - 适合设计：床上侧躺、沙发躺、草地俯卧、手托脸的躺姿。

7. 两只手分别执行不同动作
   - 单变量 bad 率约 31.0%。
   - 一只手抬起、一只手拿物/插兜/扶物时，左右手语义不对称，模型更容易错接、漏接或多生成。
   - 适合设计：一手扶头发，另一手拿杯；一手搭栏杆，另一手插兜；一手托脸，另一手拿花。

三、风险特征叠加规律
- 0 个确认风险特征：bad 率约 16.9%。
- 1 个确认风险特征：bad 率约 26.7%。
- 2 个确认风险特征：bad 率约 26.4%。
- 3 个确认风险特征：bad 率约 65.4%，两 seed 都 bad 模板占比约 53.8%。
- 因此设计坏手生成 prompt 时，不要只加一个风险因素，优先叠加 3 个左右：例如“全身 + 抱膝/盘腿 + 双手托脸/持物”。

四、推荐用于生成坏手样本的 prompt 设计方向
A. 高风险组合 1：盘腿/抱膝 + 手靠近脸 + 中全景
   示例要素：人物坐在窗台/沙发/地毯上，双腿盘起或抱膝，双手托住脸颊，头发垂落遮挡手腕，中全景，人物占画面三分之二。

B. 高风险组合 2：全身 + 持物 + 手脚同时入镜
   示例要素：全身站立或坐姿，双手抱花束/吉他/书/杯子，脚踝、鞋、靴子清晰入镜，复杂衣袖或手套。

C. 高风险组合 3：一手抬起靠近头发 + 另一手拿物/插兜
   示例要素：一只手撩发或扶额，另一只手拿包/杯子/花/手机，肩膀侧转，衣袖宽松，头发和手腕部分重叠。

D. 高风险组合 4：躺姿 + 托脸/抱物
   示例要素：人物侧躺在床/沙发/草地上，一只手托腮，另一只手抱枕/花束/书，身体有透视缩短。

E. 高风险组合 5：多画面/多姿态拼贴
   示例要素：同一人物三连拍或四宫格，每格不同动作：托脸、拿花、扶栏杆、整理头发；小画面但手部需要清楚。

F. 高风险组合 6：多人互动 + 持物/拥抱
   示例要素：情侣/朋友同框，手搭肩、抱腰、互相递花/杯子，手臂交叉遮挡。该项单独风险不算最高，但与持物/遮挡叠加后更容易产生手臂归属错误。

五、可以直接套用的中文提示词模板
1. 保持人物脸部特征绝对一致，中全景人像视角，人物坐在复古窗台上，双腿盘起并交叠，双手托住脸颊两侧，头发自然垂落并部分遮挡手腕，人物占据画面三分之二，窗边柔和逆光，高清写实摄影。

2. 保持人物脸部特征绝对一致，全身人像视角，人物坐在地毯上抱膝，膝盖靠近胸口，一只手环抱小腿，另一只手轻扶脸颊，脚踝和鞋子清楚入镜，宽松长袖衣服形成复杂遮挡，电影感自然光。

3. 保持人物脸部特征绝对一致，中全景平视视角，人物一只手抬起整理头发，另一只手握着花束靠近胸前，肩膀微微侧转，发丝、手指、花束边缘相互遮挡，背景为复古室内柔焦光影，高清真实人像。

4. 保持人物脸部特征绝对一致，人物侧躺在柔软沙发上，一只手托住下巴，另一只手抱着打开的书本，手腕被袖口和书页部分遮挡，身体呈对角线构图，浅景深写真人像。

5. 保持人物脸部特征绝对一致，四宫格时尚杂志拼贴，同一人物在四个小画面中分别做出托脸、撩发、扶栏杆、双手捧花动作，每个小画面都是中近景，手部动作清晰但姿势复杂，高清写真风格。

6. 保持人物脸部特征绝对一致，全身街拍视角，人物站在便利店冷藏柜前，一只手高举扶住柜门边缘，另一只手插进口袋，身体侧身，玻璃反光和宽松外套遮挡手臂边缘，冷暖霓虹光影。

7. 保持人物脸部特征绝对一致，双人情侣同框，一人从背后环抱另一人，两人的手臂在胸前和腰间交叉，前景人物手捧花束，后景人物手搭肩膀，手部归属复杂，真实摄影质感。

六、为了更容易得到“坏手”的提示词写法建议
- 优先写复杂手部动作：托脸、撩发、扶额、抱膝、握物、双手捧物。
- 优先加入遮挡：头发遮手腕、衣袖遮手掌、花束/杯子/书本遮手指、栏杆/门框与手重叠。
- 优先使用中全景/全身，而不是极近景手部特写；全身会降低手部像素，增加错误率。
- 优先让两只手动作不对称：一只手靠近头，另一只手拿物或插兜。
- 可增加复杂服装：长袖、蕾丝手套、宽松袖口、婚纱、披肩、透明纱、复杂首饰。
- 可增加复杂构图：侧身、躺姿、俯拍、镜面反射、拼贴、多姿态、多人互动。

七、不太容易坏手的相对低风险场景
- 手臂自然下垂是明显低风险，bad 率约 6.2%。
- 简单正面站立、双手自然垂放、无持物、无遮挡、半身清晰人像通常不利于生成坏手样本。
- 如果目标是专门扩充坏手异常样本，应减少这类“手臂自然下垂、动作简单、无道具接触”的 prompt。

八、标签设计建议
- 如果生成目标是“坏手异常训练集”，建议将上述高风险 prompt 生成结果再经过人工/VLM 筛选，只有真正出现额外手、手腕分叉、多手连接、明显手臂归属错误的图片才进入 abnormal。
- 不建议只根据 prompt 高风险直接标 abnormal，因为报告也说明关键词 AUC 只有 0.594，prompt 风险不是确定标签。
- 对于持物、多人、拼贴图，尤其要区分“合理多个人/多画面导致手多”与“单个人体结构异常多手”。
